# blueprint-engine

A research pipeline that finds top-performing game-design content (YouTube, TikTok, Roblox
Creator Docs, Roblox DevForum) and turns it into **evidence-backed implementation blueprints**
and a **prompt framework** for designing Roblox games. It focuses on core loops, retention,
onboarding/UX, monetization and discovery.

**Start here:** [`reports/IMPLEMENTATION_REPORT.md`](reports/IMPLEMENTATION_REPORT.md) is the
synthesised report. The rest of `reports/` is regenerated by the pipeline:

| Output | What it is |
|---|---|
| [`reports/IMPLEMENTATION_REPORT.md`](reports/IMPLEMENTATION_REPORT.md) | Curated strategy, per-pillar build specs, roadmap, instrumentation, guardrails |
| [`reports/evidence-report.md`](reports/evidence-report.md) | Auto-generated: every mechanic ranked by cross-source consensus, with timestamped quotes |
| [`reports/blueprint.json`](reports/blueprint.json) | Machine-readable blueprint (sources, scores, mechanics, evidence, playbook) |
| [`reports/prompt-framework/`](reports/prompt-framework/README.md) | 12 game-design prompts, pre-filled with the research |

## How it works

```
discover ──► fetch ──────────────► analyze ──────────────► synthesize
 yt-dlp       metadata + ranking     segmentation           cross-source consensus (P0/P1/P2)
 search       caption tracks         taxonomy (5 pillars,   curated Roblox playbook
 TikTok feeds docs article text        39 mechanics)        stale-advice checks vs first-party docs
 docs seeds   Discourse threads      actionability scoring  evidence report + prompt framework
 DevForum                            (or Claude extractor)
```

- **Ranking:** `score = performance × (0.25 + 0.75 × relevance)`. Performance blends view
  velocity, like rate and channel authority; relevance is taxonomy fit gated by a
  developer-intent signal, so viral gameplay videos cannot outrank design talks. Forum threads
  must name a design topic in the title. Roblox docs and staff posts count as first-party.
- **Transcripts:** caption tracks via yt-dlp (manual captions over original-language ASR;
  machine translations rejected), with `youtube-transcript-api` as a fallback. Auto-captions
  are re-segmented into sentences using punctuation, pauses and spoken discourse markers.
- **Extraction:** the heuristic extractor is offline and deterministic. It scores directives,
  imperatives, causal reasoning, numbers and stated principles; it penalises click-path
  procedure; and it filters sponsor reads and creator-code plugs. The optional Claude extractor
  (`--extractor claude`, model `claude-opus-5-5`) returns schema-constrained insights, and every
  quote is checked against the source text.
- **Synthesis:** mechanics are counted by **distinct sources** and weighted by source score and
  actionability. Evidence is chosen for strength, readability and source diversity. A curated
  Roblox playbook (verified API names, KPIs, pitfalls) is attached, and advice that contradicts a
  first-party deprecation is flagged.
- **Performance:** network stages run on a thread pool behind one shared rate limiter. Every
  result is cached per item (`data/`), so stages are resumable and re-runs only fetch what is new.
  A full run (~200 candidates, ~200k words) takes about 2 minutes cold and seconds warm.

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e '.[dev]'                 # add '[llm]' for the Claude extractor
bpe run                                 # all stages
bpe status                              # cache counts
bpe prompts list
bpe prompts render core-loop-designer --var game_concept="co-op pet battler" --var genre=simulator \
    --var target_session_minutes=20
```

Individual stages: `bpe discover`, `bpe fetch`, `bpe analyze [--extractor claude]`,
`bpe synthesize`. Add `--refresh` to ignore caches and `-v` for debug logs.

### Configuration

- [`config/research.toml`](config/research.toml): pillars and search queries, the doc pages to
  read, TikTok handles, DevForum searches, and ranking thresholds.
- [`config/key-findings.md`](config/key-findings.md): curated close-reading findings per pillar,
  injected into the matching prompts.
- Prompt templates live in
  [`src/blueprint_engine/prompts/templates/`](src/blueprint_engine/prompts/templates/). They are
  Markdown with front matter and `{{slots}}`.

### Network

The pipeline needs `www.youtube.com`, `youtube.com`, `www.tiktok.com`, `create.roblox.com`
and `devforum.roblox.com` (plus PyPI to install). From cloud IPs YouTube blocks the timedtext
endpoints used by most transcript libraries; yt-dlp's caption tracks still work there. TikTok
search is broken upstream in yt-dlp, so TikTok is ingested from creator handles or video URLs.
The DevForum stage skips itself while the forum redirects to its maintenance page.

## Data policy

Raw transcripts and page text are third-party content. They stay in the local cache (`data/`,
git-ignored) and can be re-fetched. Committed reports contain only scores and short,
attributed excerpts with deep links back to the source.
